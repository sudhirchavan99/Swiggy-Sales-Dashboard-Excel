# 📊 Swiggy Sales Analysis Dashboard (Excel)
## 📌 Project Overview

This project presents an **interactive Excel Dashboard** built to analyze **Swiggy food delivery sales performance** across multiple dimensions such as sales trends, order volume, ratings, food categories, cities, and states.

The dashboard helps stakeholders quickly understand business performance and make **data-driven decisions.**
# 
## 🎯 Objectives
- Analyze overall sales performance
- Track monthly, weekly, and daily trends
- Compare Veg vs Non-Veg sales
- Identify top-performing cities and states
- Monitor average order value and customer ratings
- Build a visually interactive Excel dashboard
# 
## 📂 Dataset Information

The dataset contains the following key attributes:
- Order ID
- Order Date
- City
- State
- Food Category
- Restaurant Name
- Order Value
- Rating
- Food Type (Veg / Non-Veg)

Dataset is included in the Excel file.

## 🚀 Key Insights From Analysis
- Bangalore is the highest revenue generating city
- Non-Veg food contributes nearly 63% of total sales
- Sales peak during weekends (Saturday & Sunday)
- Q2 recorded the highest quarterly sales
- Average customer rating remains consistently above 4.3
